Install Verseform for Word

Add authorized Scripture to Word without leaving your document. This pilot has no Verseform account, advertising, analytics, or document upload.

Download the Word add-in

Install in Word on the web

  1. Download the add-in file above.
  2. Open a document in Word on the web using the browser profile where you will use Verseform.
  3. Choose Home → Add-ins → More Settings → Upload My Add-in.
  4. Select verseform-for-word.xml, then choose Upload.
  5. Type a reference such as John 3:16 and choose Fill Scripture from Word’s Home ribbon.

What persists

The ribbon command remains registered in that browser profile, and Preview & Settings does not need to stay open. Clearing browser data or switching browsers requires uploading the add-in again. This manual web pilot does not install Verseform into Word Desktop.

Scripture service is provided by Digital Bible Society. Preview or insertion sends only translation, book, and chapter coordinates—not document prose or file names.
