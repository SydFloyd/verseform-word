How to use Verseform

  1. Type a reference such as John 3:16.
  2. Leave the cursor in or immediately after that one reference.
  3. Choose Fill Scripture from Word’s Home ribbon.
  4. Use Word’s Undo command to restore the reference if needed.

You can preview or change translations here. Verseform supports one chapter and up to 25 verses per reference; split a longer passage into smaller ranges.

Private by design

Detection stays in Word. A preview or insertion sends only the selected translation, book, and chapter coordinates to DBS—never your document prose or file name.
