## Scope gates

- **Current VFW-040 host boundary:** Word 16.0.20326.20132 keeps the shared runtime and local annotations alive while hidden but delivers native annotation clicks only with the pane visible. `D-025` contains that boundary with the approved explicit **Fill Scripture** ribbon/context-menu command; automatic replacement on selection change remains prohibited. Under `D-029`, public release still depends on `D-011`, DBS approval, hosted-manifest validation, context-menu proof, accessibility proof, and a Mac host walk because the manifest admits Mac.

- VFW-010 closed the host feasibility gate with click and keyboard activation; hover remains best effort under `D-014`.
- VFW-020 may persist authorized provider responses only after cache age, byte, entry, schema, clear, and removal bounds are executable and no document prose enters the cache.
- VFW-030 closes only the English detector. `D-017` prevents multilingual implementation or claims before DBS product approval, English-pilot feedback, and a later language-specific corpus plus Word offset proof.
- VFW-040 cannot publish under DBS until DBS explicitly accepts that role, `D-011` resolves production hosting, support, and publisher identity, and every platform admitted by the production manifest passes certification proof.
